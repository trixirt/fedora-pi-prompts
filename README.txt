Open source AI tools are essential for projects like Fedora. The philosophy of
transparency, collaboration, and freedom that defines Fedora should extend to
parts of the development process. Utilizing open source AI ensures that the
ecosystem remains unbiased, customizable, and free from vendor lock-in,
guaranteeing that the future of open source development remains in the hands
of the community.

This project serves as a repository for self-contained prompt files designed
to support the Fedora Linux project. These files are intended to be used with
pi, a coding agent available in the pi-coding-agent RPM package.  For more
information see https://fedoraproject.org/wiki/SIGs/AI-ML#pi-coding-agent

**Example Usage**

To generate comments for patches in spec file

    pi < fedora-review/fedora-rpm-patch.xml


This project is a work in progress. We welcome contributions and
collaboration to expand the library of prompts and improve the
efficiency of agentic workflows within the Fedora project.
